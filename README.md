# 🛠️ Dynamic Portfolio Page – Interior Designer

This project is a dynamic web page built with vanilla JavaScript. It showcases an interior designer's work and includes admin features like login and media upload — all powered by interaction with an API.

Refreshed in **July 2025** to improve structure, clarity, and presentation.

## 🚀 Project Features

- 📸 **Gallery Display**: Projects are loaded dynamically from an API
- 🔒 **Admin Login Page**: Secure form to access the admin area
- 🗂️ **Upload Modal**: Upload new media via a custom-built modal
- 🧠 **Vanilla JS**: No frameworks — built from scratch
- 🌐 **API Integration**: Uses `fetch()` to communicate with a real backend

## 🎯 What I Learned

- How to structure DOM manipulation using clean JS
- Handling async API calls with `fetch`
- Creating and validating login forms
- Building modals and managing user input
- Version control with GitHub
- Working from Figma mockups for UI consistency
